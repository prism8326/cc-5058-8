怎样启动（界面操作）

  1. 在下方“测试案例”选择场景（默认标准协作）。
  2. 在“发起方”选择角色 A 或 B。
  3. 点击 发起协作：两名角色按各自路径接近接触点。
  4. 自动模式下，双方真实就位 → READY → COMMIT → FORCE → 搬运 → RELEASE 自动推进； 取消勾选可手动逐协议按钮驱动。
  5. 观察结果区与调试视图；任何协议拒绝/失败都会回显。
